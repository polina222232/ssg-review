Static Site Generator — инструмент, генерирующий HTML-страницы на этапе сборки из шаблонов и контента (Markdown, JSON, CMS).

Hugo написан на Go и компилируется в один бинарник. Jekyll — на Ruby, работает медленнее, особенно на больших проектах.

Да, Gatsby отлично интегрируется с Contentful, Strapi, Sanity, WordPress через GraphQL-плагины.

GitHub Pages, Netlify, Vercel, Cloudflare Pages — все бесплатны для личных проектов.

Нет. Собранный сайт — это набор HTML/CSS/JS-файлов, которые можно раздавать с любого CDN или статического хостинга.

Если вы знакомы с JS/React — Gatsby. Если хотите максимальную скорость и простоту — Hugo. Если нужен GitHub Pages «из коробки» — Jekyll.
