Сравнение Gatsby, Hugo, Jekyll

Полная таблица характеристик трёх популярных SSG.

Сравнение по ключевым критериям
Критерий Gatsby Hugo Jekyll
Язык JavaScript / React Go Ruby
Скорость сборки Средняя Очень высокая Низкая
Шаблоны React / JSX Go templates Liquid
Данные GraphQL Front Matter, Data Front Matter
Установка Node.js + CLI Один бинарник Ruby gem
GitHub Pages Через Actions Через Actions Нативно
Плагины Очень много Средне Много
Порог входа Высокий Низкий Низкий
Для кого React-разработчики Все Начинающие

Скорость сборки (визуально)

Gatsby 60%
Hugo 95%
Jekyll 30%

Быстрый старт для каждого

Gatsby Hugo Jekyll
bash Копировать 
npm install -g gatsby-cli
gatsby new my-site
cd my-site
gatsby develop
bash Копировать 
choco install hugo-extended -y
hugo new site my-site
cd my-site
hugo server -D
bash Копировать 
gem install jekyll bundler
jekyll new my-site
cd my-site
bundle exec jekyll serve
