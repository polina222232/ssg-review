Главная Gatsby

Gatsby

React-based генератор статических сайтов с GraphQL-слоем данных.

Gatsby использует React для шаблонов и GraphQL для получения данных из Markdown, CMS, API. Идеален для блогов, документации, лендингов и e-commerce на Shopify.

React GraphQL SSG Node.js

Ключевые особенности

  • React + JSX для компонентов
  • GraphQL как единый слой данных
  • Огромная экосистема плагинов
  • Оптимизация изображений «из коробки»
  • Интеграция с Netlify, Vercel, Gatsby Cloud

Установка

bash Копировать 
# Установка CLI
npm install -g gatsby-cli

# Создание проекта
gatsby new my-site https://github.com/gatsbyjs/gatsby-starter-default

# Запуск dev-сервера
cd my-site
gatsby develop
# http://localhost:8000

# Сборка продакшена
gatsby build
gatsby serve

Конфигурация gatsby-config.js

javascript Копировать 
module.exports = {
  siteMetadata: {
    title: 'SSG Review',
    siteUrl: 'https://example.com'
  },
  plugins: [
    'gatsby-plugin-image',
    'gatsby-plugin-sharp',
    'gatsby-transformer-sharp',
    'gatsby-plugin-react-helmet',
    {
      resolve: 'gatsby-source-filesystem',
      options: {
        name: 'posts',
        path: `${__dirname}/src/posts`
      }
    },
    {
      resolve: 'gatsby-transformer-remark',
      options: {
        plugins: ['gatsby-remark-prismjs']
      }
    }
  ]
};

React-компонент страницы

jsx Копировать 
import React from 'react';
import { graphql, Link } from 'gatsby';
import Layout from '../components/layout';

export default function Blog({ data }) {
  const posts = data.allMarkdownRemark.nodes;

  return (
    <Layout>
      <h1>Блог</h1>
      <ul>
        {posts.map(post => (
          <li key={post.id}>
            <Link to={post.fields.slug}>
              <h2>{post.frontmatter.title}</h2>
            </Link>
            <p>{post.excerpt}</p>
          </li>
        ))}
      </ul>
    </Layout>
  );
}

export const query = graphql`
  query {
    allMarkdownRemark(sort: { frontmatter: { date: DESC } }) {
      nodes {
        id
        excerpt
        fields { slug }
        frontmatter { title, date }
      }
    }
  }
`;

GraphQL-запрос

graphql Копировать 
query BlogPostBySlug($slug: String!) {
  markdownRemark(fields: { slug: { eq: $slug } }) {
    html
    frontmatter {
      title
      date(formatString: "DD.MM.YYYY")
      author
      cover {
        childImageSharp {
          gatsbyImageData(width: 1200, placeholder: BLURRED)
        }
      }
    }
  }
}

Деплой на GitHub Pages

yaml Копировать 
# .github/workflows/gatsby.yml
name: Deploy Gatsby to Pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: public
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
    steps:
      - uses: actions/deploy-pages@v4

Плюсы и минусы

Плюсы

  • React-экосистема
  • Мощный GraphQL
  • Много плагинов
  • Отличная документация

Минусы

  • Медленная сборка больших сайтов
  • Требует Node.js
  • Высокий порог входа
Первый запуск Gatsby может занять несколько минут — устанавливаются зависимости.
