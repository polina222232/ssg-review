Jekyll

Классический SSG на Ruby, встроенный в GitHub Pages.

Jekyll — один из первых генераторов статических сайтов. Именно он используется GitHub Pages по умолчанию. Отлично подходит для блогов, портфолио и документации.

Ключевые особенности

  • Нативная поддержка GitHub Pages
  • Шаблонизатор Liquid
  • Markdown + Front Matter
  • Плагины на Ruby
  • Простая структура проекта
  • Большое количество готовых тем

Установка

bash 
# Установка Ruby gem
gem install jekyll bundler

# Новый сайт
jekyll new my-site
cd my-site

# Запуск dev-сервера
bundle exec jekyll serve

# Сборка
bundle exec jekyll build

# С указанием окружения
JEKYLL_ENV=production bundle exec jekyll build

Liquid-шаблоны

Список постов — index.html

liquid 
---
layout: default
title: Блог
---

<h1>{{ page.title }}</h1>

<ul class="post-list">
  {% for post in site.posts %}
    <li class="post-list__item">
      <time datetime="{{ post.date | date_to_xmlschema }}">
        {{ post.date | date: "%d.%m.%Y" }}
      </time>
      <h2>
        <a href="{{ post.url | relative_url }}">{{ post.title }}</a>
      </h2>
      <p>{{ post.excerpt | strip_html | truncatewords: 30 }}</p>
      {% if post.tags.size > 0 %}
        <ul class="tag-list">
          {% for tag in post.tags %}
            <li class="tag-list__item">{{ tag }}</li>
          {% endfor %}
        </ul>
      {% endif %}
    </li>
  {% endfor %}
</ul>

Layout — _layouts/post.html

liquid 
---
layout: default
---
<article class="post">
  <header class="post__header">
    <h1>{{ page.title }}</h1>
    <time datetime="{{ page.date | date_to_xmlschema }}">
      {{ page.date | date: "%d.%m.%Y" }}
    </time>
    {% if page.author %}<p>Автор: {{ page.author }}</p>{% endif %}
  </header>
  <div class="post__content">
    {{ content }}
  </div>
</article>

Деплой на GitHub Pages

yaml 
# .github/workflows/jekyll.yml
name: Build and Deploy Jekyll
on:
push:
branches: [main]
permissions:
contents: read
pages: write
id-token: write
jobs:
build:
runs-on: ubuntu-latest
steps:

uses: actions/checkout@v4

uses: ruby/setup-ruby@v1
with:
ruby-version: '3.2'
bundler-cache: true

run: bundle exec jekyll build

uses: actions/upload-pages-artifact@v3
with:
path: _site
deploy:
needs: build
runs-on: ubuntu-latest
environment:
name: github-pages
steps:

uses: actions/deploy-pages@v4
