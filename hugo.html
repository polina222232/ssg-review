Главная Hugo

Hugo

Самый быстрый генератор статических сайтов, написанный на Go.

Hugo собирает тысячи страниц за доли секунды. Поставляется одним бинарником без зависимостей — не нужен Node.js, Ruby или Python. Идеален для документации, блогов и корпоративных сайтов.

Go Скорость SSG Один бинарник

Ключевые особенности

  • Скорость сборки — рекордная
  • Один бинарник — нет зависимостей
  • Go templates + Shortcodes
  • Мультиязычность «из коробки»
  • Встроенный pipeline для CSS/JS
  • Поддержка Taxonomies

Установка

bash Копировать 
# Windows (Chocolatey)
choco install hugo-extended -y

# macOS (Homebrew)
brew install hugo

# Linux (Snap)
sudo snap install hugo

# Создание нового сайта
hugo new site my-site
cd my-site

# Добавить тему
git init
git submodule add https://github.com/theNewDynamic/gohugo-theme-ananke themes/ananke
echo "theme = 'ananke'" >> hugo.toml

# Запуск
hugo server -D

# Продакшен-сборка
hugo --minify

Конфигурация hugo.toml

toml Копировать 
baseURL = 'https://example.com/'
languageCode = 'ru-ru'
title = 'SSG Review'
theme = 'ananke'

[params]
  description = 'Обзор Hugo, Gatsby, Jekyll'
  author = 'Буренкова П. А.'
  mainSections = ['posts']

[markup]
  [markup.highlight]
    style = 'monokai'
    lineNos = true
    noClasses = false

[menu]
  [[menu.main]]
    name = 'Главная'
    url = '/'
    weight = 1
  [[menu.main]]
    name = 'Посты'
    url = '/posts/'
    weight = 2

[taxonomies]
  tag = 'tags'
  category = 'categories'

Шаблоны (Go templates)

Шаблон списка — layouts/_default/list.html

html Копировать 
{{ define "main" }}
  <h1>{{ .Title }}</h1>
  <ul>
    {{ range .Pages }}
      <li>
        <a href="{{ .RelPermalink }}">{{ .Title }}</a>
        <time>{{ .Date.Format "02.01.2006" }}</time>
        <p>{{ .Summary }}</p>
      </li>
    {{ end }}
  </ul>
{{ end }}

Шаблон поста — layouts/_default/single.html

html Копировать 
{{ define "main" }}
  <article>
    <h1>{{ .Title }}</h1>
    <time>{{ .Date.Format "02.01.2006" }}</time>
    {{ with .Params.tags }}
      <ul class="tags">
        {{ range . }}
          <li><a href="{{ "tags/" | relURL }}{{ . | urlize }}">{{ . }}</a></li>
        {{ end }}
      </ul>
    {{ end }}
    {{ .Content }}
  </article>
{{ end }}

Деплой на GitHub Pages

yaml Копировать 
# .github/workflows/hugo.yml
name: Deploy Hugo to Pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          submodules: recursive
      - uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: 'latest'
          extended: true
      - run: hugo --minify
      - uses: actions/upload-pages-artifact@v3
        with:
          path: public
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
    steps:
      - uses: actions/deploy-pages@v4

Плюсы и минусы

Плюсы

  • Молниеносная скорость
  • Простая установка
  • Нет зависимостей
  • Мультиязычность

Минусы

  • Go templates — не всем привычны
  • Меньше плагинов, чем у Gatsby
  • Темы иногда сложные
