О проекте

Учебный проект по фронтенд-разработке.

Сайт создан в рамках учебного проекта. Тема — «Фреймворки для статических сайтов (Gatsby, Hugo, Jekyll)». Использован UI-фреймворк Shoelace, методология БЭМ, адаптивная вёрстка mobile-first.

Технологии

  • HTML5 (семантическая валидная разметка)
  • CSS3 (Grid, Flexbox, Custom Properties)
  • Shoelace (Web Components)
  • JavaScript ES6+
  • БЭМ-методология
  • Prism.js (подсветка кода)
Shoelace БЭМ Mobile-first HTML5 CSS3 JavaScript
